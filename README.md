# 🚀 AI-Mart

AI-Mart is a centralized platform designed to help users **discover, explore, save, and submit AI tools** based on their needs. Think of it as a one-stop marketplace for AI tools — similar to how a supermarket organizes products, but for AI.

The goal of AI-Mart is to **simplify AI discovery**, remove confusion, and create a structured ecosystem where:

* Users find the right AI tools quickly
* Tool creators submit and showcase their products
* Founders/admins maintain quality and trust

---

## 🎯 Vision

With thousands of AI tools launching every year, users often feel overwhelmed.
AI-Mart solves this by:

* Categorizing tools by field and use case
* Showing verified and curated tools
* Providing dashboards for different roles

**In short:**

> *AI-Mart helps users find the right AI tool at the right time.*

---

## 👥 User Roles

### 👤 User (Default)

* Register & login
* Access personal dashboard
* Explore AI tools by category
* Save favorite tools
* Manage profile & settings

### 🧑‍💻 Tool Owner

* Apply for Tool Owner role
* Submit AI tools via form
* Manage submitted tools
* Track approval status

### 🧠 Founder / Admin

* Approve or reject Tool Owner requests
* Review AI tools before publishing
* Manage platform content & users

---

## 🧭 Core Features (Phase‑1)

### 🔐 Authentication & Security

* Register / Login
* JWT-based authentication
* Refresh token support
* Secure password hashing

### 🧑‍🎨 User Dashboard

* Personalized dashboard after login
* Navigation: Explore, Saved, Profile
* Profile picture & settings

### 🧰 Tool Management

* Tool submission by Tool Owners
* Admin approval workflow
* Categorized AI tools
